AI is not responding

Make sure the backend is running with npm start inside the backend folder and that your AI provider key is in backend/.env. If a response is still pending, keep the AI tab open; Novexa now continues active requests while the tab is in the background.

Google login

In Supabase Authentication → Providers, Google must be enabled and the redirect URL must match the URL you use to run Novexa.

Need direct help?

For an account or payment issue, include the page, the action you took, and the message you saw.
