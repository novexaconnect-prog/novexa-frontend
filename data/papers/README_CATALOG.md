# Novexa Paper Catalog

The Browse page is organized around the Edexcel IAL structure used by Paper Lords: subject → exam session → unit → QP/MS. Paper Lords recent IAL pages show, for example, Mathematics units such as P1–P4, M1–M3, S1–S3, FP1–FP3 and D1; Biology/Chemistry use Units 1–6 with A variants on some recent sessions; Business/Economics use Units 1–4; Physics uses Units 1–6.

The Google Drive archive configured for Novexa is:
https://drive.google.com/drive/folders/1iVHM4qiEmdQbU3b_JLOmx74iawd3eidd

Individual QP/MS buttons in `structure.json` accept either a Google Drive file ID or a complete URL. The current ZIP does not invent file IDs for the private Drive folder. Populate those fields from the Drive data when syncing the archive.
